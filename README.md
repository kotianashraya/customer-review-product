# 🛍️ Customer Review Product Analysis

An interactive **Streamlit-based web application** designed to analyze customer reviews and extract meaningful insights from product feedback.

## 📌 About the Project

Customer reviews contain valuable information about product quality, customer satisfaction, common complaints, and overall user experience.

This project provides an easy-to-use platform where customer review data can be analyzed to understand patterns, sentiment, ratings, and customer opinions.

The application combines **Python, data analysis, visualization, and Natural Language Processing (NLP)** concepts to transform raw customer feedback into understandable insights.

## 🎯 Objectives

- Analyze customer reviews efficiently
- Understand customer sentiment and opinions
- Identify positive and negative feedback
- Analyze product ratings and review patterns
- Present customer insights through an interactive interface
- Reduce the effort required to manually analyze large numbers of reviews

## 🚀 How to Run the Project Locally

### Step 1: Clone the Repository

```bash
git clone https://github.com/kotianashraya/customer-review-product.git
```

### Step 2: Open the Project Folder

```bash
cd customer-review-product
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the Streamlit Application

```bash
streamlit run app.py
```

The application will normally open at:

```
http://localhost:8501
```
